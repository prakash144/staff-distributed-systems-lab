Engineering notebook + laboratory + interview portfolio.

Existing repos I'd use as references

There are some good repositories you can study alongside your own.

1. Best match for your broader goal: Pravah

Abhishekkumar2021/Pravah

This is particularly interesting because it combines Kafka, Java 21/Spring Boot, PostgreSQL, Kubernetes, system-design material, ADRs, and playground exercises. It explicitly focuses on architectural decisions and distributed-system concepts.

I'd use this as a reference architecture, not copy it.

2. Kafka + Saga reference

piomin/sample-spring-kafka-microservices

Good for studying Kafka + Kafka Streams + Spring Boot + Saga/distributed transactions. It also provides Docker-based ways to run the system.

3. RabbitMQ distributed job system

nadimnesar/distributed-job-queue

Useful for studying RabbitMQ in a more production-oriented scenario: retries, priority processing, graceful shutdown, PostgreSQL, Kubernetes and observability.

4. Kafka + RabbitMQ + Spring Boot example

ENate/spring-kafka-microservices-app

This one is useful specifically because it combines Spring Boot, Kafka, RabbitMQ, databases and observability in one application.
